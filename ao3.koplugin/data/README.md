# Embedded fandom index

`fandoms/` is a snapshot of AO3's public fandom listing, packed so the plugin
can page it on a reader with little memory.

- **Source:** [archiveofourown.org/media](https://archiveofourown.org/media)
  and each category's `/media/<category>/fandoms` page.
- **Generated by:** `tools/build_fandoms.py` in the repository. Do not edit
  these files by hand.
- **Contents:** `index.lua` (ten media categories and their counts) and
  `fandoms/<category>/<letter>.tsv.z`, one file per category and letter.
  Each file is a 4-byte little-endian uncompressed length followed by a zlib
  stream; the text is TSV, `name<TAB>url<TAB>count<LF>`.
- **Numbers:** 77,535 fandom entries across the ten categories.
- **No user content:** fandom names and work counts only. No works, users,
  comments, bookmarks or other content from the archive.
- **Terms:** fandom names come from AO3 and remain associated with their
  creators and the OTW. The AO3 name and logo are OTW trademarks. See
  [the third-party notices](https://github.com/hemil2005/KO3/blob/main/THIRD-PARTY.md).

## Refreshing the snapshot

Save `00_media.html` and one page per category from the URLs above, then run:

```sh
python3 tools/build_fandoms.py <pages_dir> <output_dir> [--include-uncategorized]
```

The pages are tens of megabytes, so they are fetched only when refreshing this
snapshot — never at runtime on the device.
