# Screenshots

Every screen below is a 600 × 800 capture from KOReader's Kindle emulator.
The work-list and author-tab shots render real AO3 markup captured offline;
the other browse and detail shots use the plugin and its embedded fandom data,
with details captured from a live work. Where AO3 was unavailable or a
signed-in session was needed, the capture uses local demo data and makes no
AO3 request.

For the short tour, see the [README](../README.md).
